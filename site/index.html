1. What is an MCP client? Beginner

MCP stands for Model Context Protocol. Think of it like a universal plug: instead of every AI app inventing its own way to reach your files, your calendar, or a database, MCP gives them one shared language.

The client lives inside the AI app you use. The server is a small program that provides access to something useful — your local files, a folder of documents, a website.

Client and server talk over a simple connection. The most common one for beginners is called stdio: the server runs as a regular process on your computer, and the client sends it messages over standard input/output.

You ──► AI app (MCP client) ──► MCP server ──► your files/folders

What the client does: it tells the AI what tools the server offers, carries the AI's requests to the server, and hands the results back to the AI. The client never changes your files on its own.

2. Connecting to local files and folders

You can give an MCP client controlled access to folders on your computer so an AI can read them — no copying and pasting required.

  1. Pick one specific folder to share (not your whole computer).
  2. Start a read-only filesystem MCP server pointing at that folder.
  3. Connect the MCP client to the server.
  4. List the server's tools and try reading a file.
  5. Stop the server when you are done.
Safety first: never share folders with passwords, keys, IDs, tax returns, medical records, or bank statements. Read the safety rules before connecting real folders.

3. Building your first Python MCP client

The example client in examples/python/mcp_client.py uses only the Python standard library — nothing to install beyond Python 3, no API keys.

python3 mcp_client.py python3 servers/filesystem_server.py ./example-data

Expected output lists two tools: list_directory and read_file. Run python3 test_client.py to verify everything works (11 tests, all pass).

4. Connecting a local LLM to files, folders, and apps

The MCP client bridges a local LLM to your files, folders, and apps. The example local_llm_bridge.py demonstrates the flow with no real LLM or model download required.

python3 local_llm_bridge.py filesystem ./example-data "List the files"
python3 local_llm_bridge.py notes ./notes-data "Read welcome.md"

5. Privacy and safety rules

  • Share specific folders, never your whole computer.
  • Never share folders with secrets.
  • Prefer read-only servers.
  • You are in charge: you can remove any server at any time.
  • Assume the AI provider sees what you send it.
