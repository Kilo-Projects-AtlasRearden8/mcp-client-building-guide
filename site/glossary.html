Glossary

Building MCP Clients · Asdale Dynamics, LLC

Plain-English definitions for the terms used in this manual.

TermMeaning
MCP clientThe part inside the AI app that starts an MCP server, asks what tools it offers, and carries requests and results back and forth.
MCP serverA small program that provides access to something useful and exposes tools for an MCP client to call.
MCPModel Context Protocol — a shared language so AI apps can connect to files, folders, databases, and apps.
ToolAn action an MCP server offers, such as list_directory or read_file.
stdioStandard input/output — the most common beginner connection between client and server.
Local-firstEverything runs on your own computer; nothing is uploaded just to use a tool.
Local LLMAn AI model that runs on your machine, without sending data to a cloud provider.
JSON-RPCThe message format MCP uses: one line of JSON with jsonrpc, id, method, and result or error.
Path traversalTrying to reach a file outside a shared folder using ..; the example servers reject this.
