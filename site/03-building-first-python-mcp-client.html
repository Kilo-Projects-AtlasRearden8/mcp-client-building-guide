3. Building Your First Python MCP Client

Building MCP Clients · Asdale Dynamics, LLC

The idea

In this section you build a small MCP client in Python. It connects to an MCP server over stdio, runs the initialize handshake, lists the server's tools, and calls a tool.

The example client uses only the Python standard library — nothing to install beyond Python 3, no API keys, no network.

Start the server

client = MCPClient(["python3", "servers/filesystem_server.py", "./example-data"])
client.start()

Initialize (the handshake)

info = client.initialize()

List the tools

tools = client.list_tools()

Call a tool

result = client.call_tool("read_file", {"path": "welcome.txt"})

Close

client.close()

Run it yourself

python3 mcp_client.py python3 servers/filesystem_server.py ./example-data
Connected to server: example-python-filesystem
Available tools (2):
  - list_directory: List the files and folders in a shared folder (read-only)
  - read_file: Read the contents of a shared file (read-only)

Run the tests

python3 test_client.py

Expected output: [test] ALL TESTS PASSED (11 tests, 0 failed).
