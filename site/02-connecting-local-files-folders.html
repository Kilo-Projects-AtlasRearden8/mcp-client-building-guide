2. Connecting to Local Files and Folders

Building MCP Clients · Asdale Dynamics, LLC

The idea

You have folders of documents, notes, or books on your computer. You want an AI assistant to read them and answer questions — without you copying and pasting everything into the chat. An MCP filesystem server gives the AI controlled access to chosen folders on your machine.

Step 1: Pick the folders you want to share

Before installing anything, decide exactly which folders the AI may see. Good choices:

  • A dedicated folder you create for this purpose, such as ~/ai-readable/
  • A specific project folder
  • Your notes or drafts folder

Avoid sharing your whole home directory, folders with passwords/tax/medical/bank data, or system folders.

Rule of thumb: share only what you would be comfortable showing the AI.

Step 2: Start the filesystem server

python3 examples/python/servers/filesystem_server.py examples/python/example-data

The server is read-only and confines all access to the example-data folder, rejecting path-traversal attempts.

Step 3: Connect the MCP client

python3 examples/python/mcp_client.py python3 examples/python/servers/filesystem_server.py examples/python/example-data
Connected to server: example-python-filesystem
Available tools (2):
  - list_directory: List the files and folders in a shared folder (read-only)
  - read_file: Read the contents of a shared file (read-only)

Step 4: List the folder

python3 examples/python/local_llm_bridge.py filesystem examples/python/example-data "List the files"

Expected output lists welcome.txt and notes.md.

Step 5: Read a file

python3 examples/python/local_llm_bridge.py filesystem examples/python/example-data "Read welcome.txt"

Step 6: Confirm safety guards

python3 examples/python/test_client.py

All tests pass, including "path traversal rejected" and "unknown tool rejected".

Step 7: Disconnect when you are done

Stop the server process (Ctrl+C). The AI loses access immediately.
