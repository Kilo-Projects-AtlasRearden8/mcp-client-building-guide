# Building MCP Clients — Beginner Manual

Welcome. This manual walks you through **MCP clients** in plain English, step by
step, never condescending — like a friend would explain it.

You will learn:

1. **What MCP clients do** (`01-what-is-an-mcp-client.md`)
2. **Connecting an MCP client to local files and folders** (`02-connecting-local-files-folders.md`)
3. **Building your first Python MCP client** (`03-building-first-python-mcp-client.md`)
4. **Connecting a local LLM to files, folders, and apps** (`04-connecting-local-llm.md`)
5. **Privacy and safety rules** (`05-privacy-safety.md`)
6. **Step-by-step checklists** (`checklists/`)
7. **Printable cheat sheet** (`cheat-sheet.md`)
8. **Glossary** (`glossary.md`)

A static HTML version of this manual lives in `site/`. Open `site/index.html`
in any browser — no install needed.

## How to use this manual

- Read in order. Each section builds on the last.
- Try the Python examples in `examples/python/`. They run with nothing to
  install beyond Python 3 — no API keys, no network, no secrets.
- Work through the checklists as you go — check off each step as you complete it.
- Print the cheat sheet (`docs/cheat-sheet.md`) and keep it by your computer.

No secrets, API keys, or personal data are needed for any of the examples.
