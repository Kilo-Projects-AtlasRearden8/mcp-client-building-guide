# Checklist 3 — Safety Review Before Connecting Real Files

Goal: Review privacy and safety before connecting an MCP client to real folders.

### Before you connect any real folder
- [ ] I picked ONE specific folder to share (not my whole computer)
- [ ] The folder has no passwords, keys, IDs, tax returns, medical records, or bank data
- [ ] The folder has no other people's personal data
- [ ] I am using a read-only server where possible
- [ ] I know how to stop or remove the server (`Ctrl+C`)
- [ ] I understand the AI provider may still process what I send it
- [ ] If I am a healthcare worker, I have confirmed no real patient data is used (education only)

### When you are done
- [ ] Stop or remove the server when finished
- [ ] Confirm the AI no longer has access to the folder
